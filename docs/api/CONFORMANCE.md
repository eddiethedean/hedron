# Conformance API

Package: [`hedron-conformance`](https://pypi.org/project/hedron-conformance/).

Public surface:

- `load_bundled_fixtures()` — load published fixtures
- `run_kit(...)` — capability-level runner
- `normalize_html(...)` — `html-v1` normalization
- `ConformanceFixture`, `Capability`, `CONTRACT_VERSION`, `FIXTURE_VERSION`

See [Language-neutral conformance kit](../conformance/INDEX.md).
