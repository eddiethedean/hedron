# Release summary for adopters

The canonical release history now lives on [Releases](release-notes.md).

The verified **v1.0.0** release is tagged and published on PyPI. Use
`hedron>=1.0.0,<1.1` for public-index installs. See
[Installation](../getting-started/installation.md).

`hedron-core`, `hedron`, `edron`, `hedron-data`, `hedron-charts`, and `hedron-maps` are Stable in
the 1.0 platform. Host adapters and vendor/tooling satellites remain Beta,
and Hedron has no commercial SLA.
