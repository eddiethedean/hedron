# Release summary for adopters

The canonical release history now lives on [Releases](release-notes.md).

The coordinated **v1.2.0** release is published on PyPI. Use
`hedron>=1.2.0,<1.3` for new applications, or `hedron>=1.0.0` when maintaining a
library that tests across the compatibility floor. See
[Installation](../getting-started/installation.md).

Continue with:

- [Upgrade to 1.2](upgrade.md)
- [What’s next](whats-next.md)
- [What’s ready today](whats-ready.md)
- [Ship a Hedron app](ship.md)
- [Evaluate Hedron](evaluate.md)

`hedron-core`, `hedron`, `edron`, `hedron-data`, `hedron-charts`, and `hedron-maps` are Stable in
the 1.2 platform. Host adapters and vendor/tooling satellites remain Beta,
and Hedron has no commercial SLA.
