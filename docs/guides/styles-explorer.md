# Interactive Styles Explorer

Explore the real theme gallery with **Folio**, **Classic**, and **Aurora**, every built-in
Folio accent, light/dark modes, and mobile/tablet preview widths. Compare themes side by
side, filter resolved tokens and component contracts, and download canonical CSS,
theme JSON, or a comparison report. Selections are shareable through the full-page URL.

Looking for the visual QA app's full button matrix? Open the
[Component Explorer](component-explorer.md), which starts on its Component states screen.

## How this works

Python renders the existing [`theme-gallery` application](https://github.com/eddiethedean/hedron/tree/main/examples/theme-gallery)
at documentation build time. `hedron-sim` embeds its nine gallery screens as local
fragment routes; the published page runs no Python and sends no application requests.
The preview frames isolate Hedron's real stylesheet from the documentation theme.
Tabs, dialogs, disclosures, popovers, and native inputs use the actual component markup
and Hedron's browser enhancements, rather than approximate CSS mockups.

This is a **styles explorer, not a backend simulator**: forms do not save data;
charts, maps, math, and capture integrations show fallback styling. It does not execute
application code, inspect a live application's cascade, or validate user-authored themes.
Conformance reports are generated by the shared validator at build time, not live audits.
Use browser/OS settings for forced colors, higher contrast, reduced motion, and zoom.
For server-driven behavior, run the gallery locally:

```bash
uv run uvicorn --app-dir examples/theme-gallery app:app --reload
```

See the [styling guide](styling.md) for the vocabulary and recipes, and the
[simulator semantics](simulator-semantics.md) for offline runtime boundaries.
