# Code of Conduct

Hedron follows the Contributor Covenant. The full text (canonical for GitHub) lives at
the repository root:

- [CODE_OF_CONDUCT.md](https://github.com/eddiethedean/hedron/blob/main/CODE_OF_CONDUCT.md)

**Conduct reports:** contact maintainers privately via the
[repository owner’s GitHub profile](https://github.com/eddiethedean). Do **not** use
GitHub security advisories for Code of Conduct reports.

**Security vulnerabilities:** use GitHub
[security advisories](https://github.com/eddiethedean/hedron/security/advisories/new) —
see [SECURITY.md](SECURITY.md).
