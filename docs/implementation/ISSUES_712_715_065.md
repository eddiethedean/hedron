# Issues #712–#715 implementation record

Phase 0.65 now includes the four styling follow-ups opened after the original
integrated-styling packet. Each slice uses the existing theme, manifest, CSS
layer, and presentation-recipe authorities.

## #712 — document ambient canvas

`AmbientLayer` is a closed data object with radial, dots, grid, and mesh
patterns; accent, muted, and neutral tones; subtle or soft intensity; bounded
scale; stable order; and flow, surface, or fixed-canvas placement. `AmbientCanvas`
is the document-level name, while `AmbientBackdrop` accepts the same `layers`
argument for compatibility. Every layer is `aria-hidden`, pointer-inert, and
rendered before semantic children. The default bundle removes decoration for
print, forced colors, reduced transparency, and the existing preference fallback.

## #713 — AppShell chrome recipes

`AppShellChrome` provides compact, standard, and editorial presets plus finite
header/nav behavior, named sticky offsets, shell gap, content inset, banner
spacing, and header/footer density. `AppShell(chrome=...)` emits only stable
data policy attributes; the bundled stylesheet resolves those attributes through
presentation tokens. Mobile collapse remains the existing responsive fallback,
and print/static behavior is safe when sticky positioning is unavailable.

## #714 — authoritative presentation tokens

The presentation contract exposes `presentation_token_manifest()`, including
declared, consumed, overridden, and unconsumed values. Built-in typography,
layout, shell, surface, data, motion, and control rules reference the emitted
`--hedron-*` presentation variables with compatibility fallbacks. Theme token
overrides therefore affect built-ins without application CSS, while legacy
variables remain explicit fallbacks.

## #715 — bounded max/range conditions

`ResponsiveCondition` supports viewport/container maximums and named ranges
such as `md-to-lg`, along with class constructors for each form. Compact values
(`ResponsiveCondition("viewport", "max-lg")`) are normalized to the same
canonical representation. Recipe compilation uses a fixed condition order and
rejects contradictory or unreachable bounds; raw media queries, selectors, and
at-rules remain unavailable.
