# Content

Text, links, media, code, lists, tables, and Markdown.

- [`Heading`](heading.md) — Create an explicit heading level without inferring document hierarchy.
- [`Text`](text.md) — Render escaped text with an explicit paragraph or inline text element.
- [`Link`](link.md) — Navigate with a validated internal or external anchor.
- [`Image`](image.md) — Render an image with a validated source and required alternative text.
- [`CodeBlock`](code-block.md) — Display escaped preformatted code with an optional language hook.
- [`List`](list.md) — Render ordered or unordered items from child values.
- [`DescriptionList`](description-list.md) — Present term/value pairs as a native description list.
- [`Table`](table.md) — Render a small static data table with explicit headers.
- [`Markdown`](markdown.md) — Render Markdown through the optional, escaped content pipeline.
