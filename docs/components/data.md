# Data

Automatic rendering, tabular display, and editable data.

- [`Auto`](auto.md) — Choose an inspectable built-in renderer for a Python value.
- [`DataTable`](data-table.md) — Render typed or pre-fetched rows as an accessible bounded data table.
- [`ResourceList`](resource-list.md) — List resources with first-party density and presentation tokens.
- [`ResourceRow`](resource-row.md) — One resource entry with optional link, meta, and actions.
- [`DataEditor`](data-editor.md) — Edit bounded typed rows and submit explicit change sets.
