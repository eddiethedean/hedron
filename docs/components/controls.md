# Controls

Buttons and links for commands and navigation.

- [`HtmxLink`](htmx-link.md) — Navigate with a SafeUrl href and typed HTMX attributes for in-shell swaps.
- [`NavLink`](nav-link.md) — Alias of HtmxLink for navigation lists and AppShell side nav.
- [`Button`](button.md) — Trigger an in-page or server command with a native button.
- [`LinkButton`](link-button.md) — Navigate with an anchor styled as a prominent button.
- [`IconButton`](icon-button.md) — Create a compact native button with a required accessible label.
- [`ClipboardCopy`](clipboard-copy.md) — Copy-to-clipboard control (write-only; no clipboard read).
- [`ConfirmButton`](confirm-button.md) — Button with explicit confirmation prompt (not authorization).
- [`MenuButton`](menu-button.md) — Button that reveals a menu of actions.
