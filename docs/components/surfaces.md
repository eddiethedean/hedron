# Surfaces and status

Cards, labels, alerts, and loading placeholders.

- [`Card`](card.md) — Group a titled piece of related content in a styled surface.
- [`Surface`](surface.md) — Compose a presentation-token surface without application CSS.
- [`StyleScope`](style-scope.md) — Bound a subtree to theme, finite variant, color mode, and density markers only.
- [`Badge`](badge.md) — Display compact categorical metadata with a named tone.
- [`Alert`](alert.md) — Present an important text message using an appropriate live-region policy.
- [`Skeleton`](skeleton.md) — Reserve space for content that is still loading.
- [`StateView`](state-view.md) — Unified loading, empty, error, permission, offline, and success surface.
- [`Carousel`](carousel.md) — No-JS carousel as an ordered slide list with controls.
- [`ContextMenu`](context-menu.md) — Context menu with required overflow-button alternative.
- [`Help`](help.md) — Accessible help text associated with a control.
- [`Popover`](popover.md) — Native popover or details/summary disclosure.
- [`Timeline`](timeline.md) — Semantic ordered timeline of events.
- [`Tooltip`](tooltip.md) — Accessible tooltip / title help.
- [`AmbientBackdrop`](ambient-backdrop.md) — Finite decorative backdrop that remains inert and outside content semantics.
