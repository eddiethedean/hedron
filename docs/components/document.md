# Document and composition

Full pages, metadata, and fragment composition.

- [`Page`](page.md) — Render a complete HTML document with safe head defaults and a body.
- [`Fragment`](fragment.md) — Return several sibling nodes without adding a wrapper element.
- [`Head`](head.md) — Compose explicit document-head children when building lower-level document output.
- [`Title`](title.md) — Set the browser-tab and history-entry title.
