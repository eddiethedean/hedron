# Landmarks

Semantic regions that give a page its accessible structure.

- [`Header`](header.md) — Render the semantic `header` landmark for introductory content.
- [`Main`](main.md) — Render the semantic `main` landmark for the page's primary content.
- [`Nav`](nav.md) — Render the semantic `nav` landmark for a major collection of navigation links.
- [`Aside`](aside.md) — Render the semantic `aside` landmark for related but secondary content.
- [`Footer`](footer.md) — Render the semantic `footer` landmark for closing information for a page or section.
- [`Section`](section.md) — Render the semantic `section` landmark for a thematically grouped region.
