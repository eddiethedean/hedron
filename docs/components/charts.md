# Charts

Accessible visualization components and optional plotting adapters.

- [`LineChart`](line-chart.md) — Plot one x/y series from row mappings with an accessible fallback.
- [`MatplotlibChart`](matplotlib-chart.md) — Render a Matplotlib figure as reviewed static SVG or image output.
- [`PlotlyChart`](plotly-chart.md) — Render a Plotly figure through Hedron's bounded adapter pipeline.
- [`AltairChart`](altair-chart.md) — Render an Altair chart through the declarative visualization adapter.
