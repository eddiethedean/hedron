# Forms

Typed, labelled controls and validation presentation.

- [`Form`](form.md) — Compose a native GET or POST form with validated action URLs and optional HTMX attributes.
- [`FormField`](form-field.md) — Bind a label, help text, required state, and field error to one control.
- [`Label`](label.md) — Associate visible text with a form control ID.
- [`TextInput`](text-input.md) — Collect a single line of typed text using a constrained input type.
- [`TextArea`](text-area.md) — Collect multi-line plain text.
- [`Select`](select.md) — Choose one value from server-defined label/value options.
- [`Checkbox`](checkbox.md) — Collect one boolean choice with its visible label.
- [`RadioGroup`](radio-group.md) — Choose exactly one option from a labelled set.
- [`SubmitButton`](submit-button.md) — Submit the nearest form with consistent primary-action styling.
- [`FormErrors`](form-errors.md) — Summarize one or more form-level validation errors.
- [`AutoForm`](auto-form.md) — Generate a labelled form from a typed FormModel and optionally submit it through HTMX.
