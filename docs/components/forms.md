# Forms

Typed, labelled controls and validation presentation.

- [`Form`](form.md) — Compose a native GET or POST form with validated action URLs and optional HTMX attributes.
- [`FormField`](form-field.md) — Bind a label, help text, required state, and field error to one control.
- [`Label`](label.md) — Associate visible text with a form control ID.
- [`TextInput`](text-input.md) — Collect a single line of typed text using a constrained input type.
- [`TextArea`](text-area.md) — Collect multi-line plain text.
- [`Select`](select.md) — Choose one value from server-defined label/value options.
- [`Checkbox`](checkbox.md) — Collect one boolean choice with its visible label.
- [`RadioGroup`](radio-group.md) — Choose exactly one option from a labelled set.
- [`SubmitButton`](submit-button.md) — Submit the nearest form with consistent primary-action styling.
- [`FormErrors`](form-errors.md) — Summarize one or more form-level validation errors.
- [`AutoForm`](auto-form.md) — Generate a labelled form from a typed FormModel and optionally submit it through HTMX.
- [`CameraCapture`](camera-capture.md) — Camera capture file input (capture=environment).
- [`ChipInput`](chip-input.md) — Free-text chip/tag multivalue input.
- [`ColorInput`](color-input.md) — Native color picker input.
- [`DateInput`](date-input.md) — Native date input.
- [`DateTimeInput`](date-time-input.md) — Native datetime-local input.
- [`DirectoryUpload`](directory-upload.md) — Directory upload input with server-side validation helper.
- [`GeolocationButton`](geolocation-button.md) — Spoofable geolocation form fields with progressive enhancement.
- [`MicrophoneCapture`](microphone-capture.md) — Microphone capture file input (capture=user).
- [`MultiSelect`](multi-select.md) — Native multi-select control.
- [`NumberInput`](number-input.md) — Native number input.
- [`Pills`](pills.md) — Pill-styled segmented choice group.
- [`RangeInput`](range-input.md) — Native range slider input.
- [`RatingInput`](rating-input.md) — Accessible 1..n rating radios.
- [`SegmentedControl`](segmented-control.md) — Segmented radio control group.
- [`SelectSlider`](select-slider.md) — Range input with optional datalist marks.
- [`TimeInput`](time-input.md) — Native time input.
- [`ToggleSwitch`](toggle-switch.md) — Switch-styled checkbox control.
