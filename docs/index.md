# Build with Hedron

[Hedron](guides/why-hedron.md) is a Python UI framework for building server-rendered
applications on FastAPI. Compose interfaces in Python, keep ordinary HTTP underneath,
and add HTMX or Alpine only where interaction needs them.

</header>
