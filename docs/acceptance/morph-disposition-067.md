# Morph disposition for Phase 0.67

`@alpinejs/morph` is vendored and demand-loadable at the exact 3.16.3 pin, but it is not the
canonical replacement engine in 0.67. Ordinary HTMX replacement remains the Supported path and
resets disposable Alpine state unless a versioned preservation contract says otherwise.

Morph remains `Progressive` until a three-engine probe proves stable identity, focus, cleanup,
OOB/history behavior, stale-state rejection, HTMX request ownership, and keyboard/accessibility
parity. No Hedron component or interaction implicitly enables Morph, and the presence of its asset
does not imply admission. This is an explicit non-admission, not an undocumented omission.
