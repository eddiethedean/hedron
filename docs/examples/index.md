# Examples

Three ways to try Hedron:

1. **[Single-file apps](single-file.md)** — `pip install hedron` and paste an `app.py`
   (no monorepo clone).
2. **[Runnable examples](runnable.md)** — clone the repo for the reference app,
   Flask/Django adapters, and HDJ sample.
3. **[Component gallery](gallery.md)** — in-browser **simulations** on Read the Docs
   (not a live Hedron process).

Start with the [reference app walkthrough](reference-app.md) when you want CRUD,
CSRF, and HTMX in one place.
