# Examples

Two kinds of examples live in the docs:

1. **[Runnable examples](runnable.md)** — clone the repo and run a real Hedron server
   (FastAPI reference app, Flask/Django adapters, HDJ sample).
2. **[Component gallery](gallery.md)** — in-browser **simulations** for layout and
   interaction patterns on Read the Docs (not a live Hedron process).

Start with the [reference app walkthrough](reference-app.md) when you want CRUD,
CSRF, and HTMX in one place.
