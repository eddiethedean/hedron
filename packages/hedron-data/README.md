# hedron-data

Data application toolkit for Hedron: `DataTable`, `DataEditor`, typed data-source
protocols, optional dataframe normalization, and a Tabulator-backed grid Web
Component.

```bash
pip install "hedron-data>=0.19.0,<0.20"
# Optional dataframe extras:
pip install "hedron-data[dataframes]>=0.19.0,<0.20"
```

Requires `hedron-core`. Coordinated train: **`0.19.0`** (Beta; Ready to cut on `main`;
last published PyPI/git = `v0.18.0`).
