# Phase 0.67 browser notices

Hedron vendors the minified browser distributions of Alpine.js `3.16.3` and
its official MIT-licensed packages. The package name, npm integrity, source,
local path, and maturity are recorded in `ALPINE_067_SUPPLY.json`.

Upstream project: <https://github.com/alpinejs/alpine>

The vendored files are used as browser assets only. Hedron does not copy or
vendor the separately licensed Alpine UI Components product, examples, or
subscriber material. The open-source `@alpinejs/ui` package is included only
as the exact MIT-licensed npm artifact and remains Progressive until each
widget family passes the Phase 0.67 evidence gates.
